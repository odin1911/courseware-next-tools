# KJ_QAP_MW_v2 交互动画无 DragonBones 替代可行性说明

本文是 [视频动画替代功能可行性分析报告](./视频动画替代功能调研报告.md) 的补充，说明包含动态文本、独立点击和拖拽等能力的交互动画，如何在不使用 DragonBones 的情况下实现。

## 分析目标

对 `KJ_QAP_MW_v2` 椰子树动画进行可行性分析，目标为：

1. 后续不再手工制作 DragonBones 动画。
2. 本模板最终实现不依赖 DragonBones 资源和运行时。
3. 在适合的场景中使用 AI 生成视频替换动画。
4. 明确无法通过视频完整保留、需要删除或降级的现有效果。

## 可行性结论

根据现有动画职责和交互流程分析，本模板可以在不依赖 DragonBones 资源和运行时的情况下保留核心玩法，但不能使用 AI 视频等价替换全部现有动画。

椰子树和椰子同时承担动态文字、独立点击、位置变化及拖拽等交互职责。视频只能提供合成后的画面，无法直接提供独立椰子节点及其交互能力。因此，树与椰子的交互部分应改为静态资源加 DOM 节点，AI 视频主要用于爆炸等不参与交互的纯展示动画。

该方案尚未进行 DEMO 验证，具体交互效果需要在正式实现阶段确认。

## 替代方案

### 椰子树

- 当前没有可直接使用的静态素材，正式实现前需要制作不带椰子的静态树图。
- 使用静态图片展示椰子树。
- 不再播放树的 DragonBones 抖动动画。
- 六颗椰子的初始位置通过独立布局工具配置，不由本模板自动识别椰子挂点。
- 如果以后更换树资源，需要在布局工具中重新完成位置对齐。

### 树上椰子

- 正式实现前需要制作透明背景的独立椰子图。
- 六颗椰子使用独立 DOM 节点展示，并按照布局工具提供的位置放置在树上。
- 椰子文字由运行时动态显示，继续支持不同题目内容。
- 每颗椰子保留独立点击、音频和显隐能力。

### 椰子掉落与拖拽

- 不使用 AI 视频表现椰子掉落。
- 直接移动当前椰子的 DOM 节点完成掉落效果。
- 掉落完成后继续使用该 DOM 节点进行拖拽、命中判断和错误返回。
- 掉落轨迹、时长和交互时序在最终实现阶段确定。

### 爆炸反馈

- 爆炸只承担视觉反馈，不包含动态文字、点击或拖拽行为。
- 适合使用 AI 生成视频替换。
- 沿用主报告中的 WebM、MOV 和 PNG 图集三格式分流方案。

## 从当前动画中删除或降级的内容

### 删除的内容

1. **树的抖动动作**  
   删除树干、树叶整体抖动的 `shake` 动画。

2. **椰子与树枝的骨骼联动**  
   删除六颗椰子随各自树枝产生不同幅度位移和旋转的效果。

3. **复杂的前后遮挡**  
   删除椰子在树叶前后动态穿插的层级效果，DOM 椰子使用固定显示层级。

4. **骨骼节点位置跟踪**  
   不再依赖动画运行时持续提供六颗椰子的节点位置及动画结束位置。

### 降级的内容

1. **六套独立掉落动画**  
   当前 `fall_0` 至 `fall_5` 的不同骨骼掉落轨迹，降级为 DOM 节点的通用掉落动画。

2. **掉落过程中的复杂变化**  
   不再要求复现原动画中的复杂弧线、独立旋转、缩放和树枝脱离效果；最终保留的动作幅度由实现阶段确定。

3. **动画与拖拽的骨骼坐标交接**  
   不再从骨骼动画最终帧读取位置，改为由同一个 DOM 椰子完成掉落和后续拖拽。

## 预计可保留的核心能力

- 通过布局工具配置六颗椰子的固定位置。
- 椰子上的动态字母或单词。
- 题目与椰子位置的运行时分配。
- 单独点击椰子播放对应音频。
- 椰子掉落和后续拖拽。
- 正确、错误命中判断。
- 错误后返回原位。
- 正确后隐藏对应椰子。
- 爆炸反馈和完成状态。

## 方案边界

本结论只判断方案是否可行，不规定以下实现细节：

- 点击后的具体交互顺序。
- DOM 掉落动画的轨迹、时长和缓动参数。
- 动画期间的交互冲突处理。
- 爆炸视频的画面尺寸、帧率和具体视觉效果。

这些内容可在进入正式实现阶段后根据实际效果继续调整。
